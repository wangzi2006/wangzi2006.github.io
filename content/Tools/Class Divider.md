## 背景

**任务描述：** 将学生分班，使得各个班级的情况尽可能平均

**需求来源：** 初高中开学分班；高中选课分班

## 使用说明
### 使用方法
1. 预处理 Excel 表格

2. 打开 [分班程序网站](https://wangzi2006.github.io/class-divider/)

3. 按照网站的要求一步步做即可：
	1. 选择姓名列、分班数、学生所在行、学科成绩列；
	
	2. 选择标签列。支持一下两种输入格式：
	   - 只含有 0 或 1 的标签列。所有标记为 1 的会被分均匀
	   - 类别列。如 “学生类别” 一列含有 “艺术生” “体育生” 或空白，则会将艺术生、体育生分匀；空白不展开。
	
	3. 设置 Top K / Bottom K，程序会将前 K 名或后 |K| 名分均匀。
	
	4. 粘贴约束文本，例如：
	   ```
	   张三,李四,不在同班
	   王五,赵六,必须同班
	   孙七,固定班级,3
	   ```
	
	5. 设置退火参数（可保持默认）、学科权重、标签权重
	
	6. 点击 “开始” 运行程序。运行完成后下载 `分班结果.xlsx`


导出的 Excel 包含：学生分班情况、各班学科均值、各班标签人数、各项极差、参数信息。

### 权重分配 Cheating Sheet

妈妈：
- 特殊要求70，男女40，艺术体育40；学校分匀1；
- 总分平均分10，语文数学平均分5，英语科学平均分3；
- 总分分数段10，语文数学分数段2，英语科学分数段1；

爸爸：
- 特殊要求70，男女40，艺术体育40；
- 总分平均分20，学科平均分6；
- 总分分数段3，学科分数段1；
